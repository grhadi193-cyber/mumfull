# سامانه مدیریت مشاوران تحصیلی

## اجرای فرانت‌اند

```sh
npm ci
npm run dev
```

دکمه‌های ورود آزمایشی بدون بک‌اند کار می‌کنند. اطلاعات نمونه و تغییرات آن‌ها فقط در localStorage همان مرورگر نگهداری می‌شوند و نباید برای اطلاعات واقعی یا حساس استفاده شوند. برای بازگرداندن داده‌های نمونه، اطلاعات سایت را از مرورگر پاک کنید.

فرم ورود عادی به `/api` درخواست می‌فرستد و به بک‌اند جداگانه نیاز دارد. در حالت توسعه، Vite درخواست‌های `/api` را به `http://localhost:8000` پراکسی می‌کند؛ برای تغییر مقصد می‌توانید متغیر محیطی `API_PROXY_TARGET` را تنظیم کنید. در نسخهٔ ساخته‌شده، سرویس‌دهنده باید مسیر `/api` را به بک‌اند هدایت کند.

برای اجرای آزمون‌ها از `npm test` استفاده کنید.
